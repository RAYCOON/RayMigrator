## External DAL plugins

If you write a DAL plugin that loads into a RayMigrator process:

- Your plugin source code is your property under your chosen license — the
  RayMigrator license does not extend to it.
- However, **using your plugin in a RayMigrator process** is governed by
  RayMigrator's license terms (BUSL-1.1 + Additional Use Grant) just like
  any other production use.

The `Raycoon.RayMigrator.Database.Example` skeleton is MIT-licensed (see
`Raycoon.RayMigrator.Database.Example/LICENSE.md`) so you can freely copy
it as a starting point for your plugin.

## Process

1. Fork the repository
2. Create a feature branch
3. Submit a Pull Request
4. Confirm the CLA in the PR template
5. Wait for review

---

## Guidelines

- Keep changes focused
- Follow existing coding style
- Avoid adding unnecessary dependencies
- All code, comments, commit messages, and documentation must be in English

Contributions are voluntary and not compensated.
